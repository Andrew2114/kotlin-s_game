# Mastermind Game

## Описание
Игра Mastermind с графическим интерфейсом на JavaFX. Приложение позволяет администрировать процесс игры: администратор загадывает секретную комбинацию, два игрока по очереди пытаются её отгадать. Поддерживается сохранение статистики в SQLite базе данных.

---

## Правила игры

### Компоненты игры
- **6 цветов**: красный (RED), зелёный (GREEN), синий (BLUE), жёлтый (YELLOW), оранжевый (ORANGE), фиолетовый (PURPLE)
- **4 позиции** в кодовой комбинации
- Цвета **могут повторяться** в комбинации

### Цель игры
Угадать секретную комбинацию из 4 цветов за **не более чем 12 ходов**.

### Ход игры

1. **Начало партии** — администратор загадывает секретную комбинацию из 4 цветов.
2. **Ход игрока** — игрок вводит свою комбинацию из 4 цветов (делает "ход").
3. **Ответ** — система даёт обратную связь с помощью маркеров:

| Маркер | Значение |
|--------|----------|
| ⚫ Чёрный | Цвет и позиция совпадают полностью |
| ⚪ Белый | Цвет присутствует в секретной комбинации, но на другой позиции |

### Правила подсчёта маркеров
1. Каждый маркер соответствует одному цвету в комбинации
2. **Сначала** подсчитываются чёрные маркеры (точные совпадения)
3. **Затем** подсчитываются белые маркеры из оставшихся цветов
4. **Важное правило дубликатов:** если в секретной комбинации цвет встречается 2 раза, а в ходе — 3 раза, то третий дубликат не награждается ни чёрным, ни белым маркером

### Окончание игры

| Результат | Условие |
|-----------|---------|
| ✅ **ПОБЕДА** | Игрок получил 4 чёрных маркера (угадал всю комбинацию) |
| ❌ **ПОРАЖЕНИЕ** | Сделано 12 ходов, а комбинация не угадана |

## Функциональность приложения

### Администрирование игры
- Администратор вводит секретную комбинацию перед началом игры
- Два игрока ходят по очереди
- Автоматический подсчёт чёрных и белых маркеров
- Автоматическое переключение хода между игроками

### Графический интерфейс (3 вкладки)

| Вкладка | Функции |
|---------|---------|
| **Игра** | Игровое поле, выбор цветов (6 кнопок), история ходов, таймер, счётчик ходов |
| **Статистика** | Статистика текущего игрока (игры, победы, проценты), таблица топ-5 игроков |
| **История** | Список всех игр текущего игрока с деталями каждого хода |

### База данных (SQLite)
- Сохранение игроков в реестр
- Сохранение всех игр и ходов
- Статистика сохраняется между запусками приложения
